# Twitter Cleaner — Site e tutorial

Site estático em português para documentar as funcionalidades e o uso do **Twitter Cleaner v1.7.2**.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub, por exemplo `twitter-cleaner-site`.
2. Faça upload de `index.html` e `README.md` na **raiz** do repositório (não envie o ZIP como um único arquivo).
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main`, pasta `/(root)`, e clique em **Save**.
6. Aguarde a publicação. O endereço normalmente será `https://SEU-USUARIO.github.io/twitter-cleaner-site/`.

> O site é apenas documentação. Ele **não contém a extensão**, não hospeda o ZIP da extensão e não executa exclusões.

## Conteúdo

- Apresentação e recursos da v1.7.2
- Instalação no Chrome/Brave
- Tutorial de busca por período, revisão, backup e exclusão por lotes
- Limitações de backup e avisos de segurança
- Perguntas frequentes

## Personalização

Edite `index.html` para mudar nome, cores, textos e adicionar capturas de tela. Não inclua dados pessoais nem backups reais de publicações no repositório público.

## Aviso

Projeto independente, sem afiliação ao X/Twitter. Ações de exclusão podem ser irreversíveis. Backups JSON/CSV não contêm necessariamente os arquivos de mídia.
